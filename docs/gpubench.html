WebGPU ORB benchmark

Times the GPU work a GPU version of ORB would do on one 480×640 frame (image pyramid, corner detection, blur, orientation and descriptors for up to 2000 corners) plus copying the results back to the CPU, 150 times. It runs in a worker, where the SLAM runs. About 30 seconds; keep the screen on. On the PC dev server the results are saved to results/browser.
