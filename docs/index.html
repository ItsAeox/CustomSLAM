Markerless SLAM in the browser

ORB-SLAM3 (monocular) compiled to WebAssembly. Everything runs on this device.

  • AR: place a tree on the floor (rear camera, hybrid ORB+KLT tracker; resize the tree with the slider)
  • AR with stock ORB-SLAM3 tracking (ORB on every frame; slower)
  • Camera calibration: film a chessboard (shown on a laptop / monitor with the same page) so the AR page uses this phone's real focal length and lens distortion instead of an assumed 69° field of view
  • Self-test: threads, SIMD, vocabulary download (33 MB) and SLAM start-up
  • XFeat benchmark: learned features (CVPR 2024) on this device, WebGPU vs WebAssembly

In the AR page, Log shows the session log (tracking losses, relocalisation, map events). Copy or download it to report a test. Algorithm options on the start screen select the tracker, descriptor and other settings.

The first visit installs a small service worker and reloads once (WebAssembly threads need it on static hosting).
