WebVIO

Markerless SLAM in the web browser: camera tracking, mapping and AR placement, running on this device.

  • AR: place a tree on the floor (rear camera; resize the tree with the slider). Choose a Preset on the start screen (baseline, hybrid ORB + KLT, hybrid fastest, light ORB, IMU); the Algorithm options below it change single settings.
  • Camera calibration: film a chessboard (shown on a laptop / monitor with the same page) so the AR page uses this phone's real focal length and lens distortion instead of an assumed 69° field of view. Needed for IMU mode (a 10 % focal error breaks the IMU's scale).

In the AR page, Log shows the session log (tracking losses, relocalisation, map events). Copy or download it to report a test.

Diagnostics

  • Self-test: checks this browser can run the SLAM (threads, SIMD, the 33 MB vocabulary download, start-up on synthetic frames). Use it when the AR page does not start.
  • XFeat benchmark: research only. Times a learned feature detector (XFeat, CVPR 2024) on this device, GPU (WebGPU) vs CPU (WebAssembly). Not used by the AR page.

The first visit installs a small service worker and reloads once (WebAssembly threads need it on static hosting).

WebVIO builds on parts of ORB-SLAM3 (GPL-3.0); credits and licence in the repository.
